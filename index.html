cheats

GameShark codes edit RAM — 01 + value + address, e.g. 010238CD writes 02 to CD38. Game Genie codes patch ROM (XXXYYY or XXXYYYZZZ with compare). Each code shows what it does underneath.

cheat finder

changed/unchanged compare against the previous scan — play a moment, then apply
search RAM while paused or playing, then narrow with changed/unchanged until a few addresses remain. freeze writes a real GameShark code into your cheat list.

shader pack
Ghosting mimics the DMG LCD's response time. The shader adds a subpixel LCD grid and optional curvature (needs WebGL; falls back to plain 2D). A shader pack replaces the built-in shader with your own GLSL (.pbg-fx); saving the file in an editor hot-reloads it.
